# 0006 · MVP4：医生开方

- 状态：第一版已实现（E2E 8 条、SQL 1 个文件、单元测试 3 个文件）

- 作者：Hao、Claude

## 1. 范围

李医生用自己的账号登录，在「诊所」里给病人开方。

1. **选病人**：搜名字或电话；没有就当场新建（名字和电话至少填一个）
2. **选药**：
   - 页面上排着拼音首字母按钮（A–Z），点一个字母，弹出这个字母开头的所有药材
   - **炮制品和原药材放在一起**：点「甘草」后可以选「甘草 / 炙甘草」；炮制品按原药材的字母归类（炙甘草在 G 下面，不在 Z 下面）
   - 也可以直接打字搜：汉字、全拼或者拼音首字母（`hq` → 黄芪）
3. **每味药**：克数（常用克数一键选）、脚注（先煎 / 后下……）、医生备注
4. **整张方子**：剂数、煎服法、医嘱、日期
5. **成本**：用诊所自己的进货价（复用 MVP2）实时算出每副和总价，**只有医生看得到**，不写进给病人的消息
6. **保存**：方子存在这个病人名下，以后可以查
7. **微信消息**：生成一段纯文本，一键复制，粘贴到微信发给病人

### 不在这次范围

- 病人自己注册、登录（病人只是诊所里的一条记录）
- 把医生开的方子导入病人自己的药柜（以后做）
- 照上一张方子加减（以后做）

## 2. 数据模型

`supabase/migrations/20261027000008_clinic.sql`：

| 变化 | 说明 |
|---|---|
| `workspaces.kind = 'clinic'` | 诊所就是另一种 workspace。成员、邀请、RLS、药柜、采购、比价都直接复用。一个人可以同时在「我们家」和「诊所」，在总览页切换 |
| `create_clinic(name)` | 创建诊所，自己是 owner，并切换过去 |
| `patients` | 诊所的病人：名字、电话、备注。名字和电话至少一个；同一诊所里电话不能重复（只比较数字，`(416) 555-0101` 和 `4165550101` 算同一个） |
| `prescriptions.patient_id` | 病人的处方。外键是 `(patient_id, workspace_id)`，**不能把别的诊所的病人挂到自己的处方上**；有处方的病人不能删 |
| `prescriptions.source = 'clinic'` | 区分医生开的方和家里录的方 |
| `prescription_items.note` | 每味药的医生备注 |
| 只有诊所能建病人 | 触发器检查 workspace 类型，家庭药柜里不能建病人 |

## 3. 微信消息格式

纯文本（微信不支持 Markdown），药材一行一味：

```
【李医生诊所】处方
日期：2026-10-27
患者：张三
共 7 剂
————————
1. 炙黄芪 18g
2. 党参 12g
3. 薄荷 3g（后下；最后 5 分钟放）
4. 炙甘草 6g
————————
煎服法：水煎服，日一剂，早晚分服
医嘱：忌生冷
```

- 脚注和医生备注放在括号里，用「；」分开；都没有就不加括号
- 没有名字的病人显示电话
- 没有医嘱就不写这一行
- 不含价格

格式由 `src/lib/rx-message.ts` 生成，单元测试覆盖每一种情况。

## 4. 隐私（PHIPA）

病人档案和处方是健康信息：

- 只有诊所成员能看（RLS，和家庭药柜同一套机制，已经过安全审查和测试）
- 家庭用户、其他诊所都看不到
- 上线前要做的：
  - Supabase 选加拿大区域
  - 和李医生确认病人同意书
  - 访问日志
  - 数据保留期限

## 5. 测试

- **单元测试**：
  - 药材索引：首字母分组、炮制品挂到原药材、没有拼音时自动补、搜索汉字/全拼/首字母
  - 微信消息的每种格式情况
  - 处方行的增删改与合并
- **SQL**：
  - 建诊所
  - 病人的 RLS
  - 电话去重（只比数字）
  - 家庭里不能建病人
  - 不能挂别的诊所的病人
  - 有处方的病人不能删
  - 药材备注
- **E2E**：医生注册 → 建诊所 → 记进货价 → 新建病人 → 用首字母按钮选药（含炮制品）、克数、脚注、备注、修改、删除 → 检查成本 → 保存 → 消息全文和测试里独立拼出来的一致 → 一键复制 → 病人档案里能查到 → 用电话后四位搜到病人再开一张 → 家庭用户看不到任何诊所数据

## 6. 测试中发现并修好的问题

| 问题 | 修复 |
|---|---|
| 搜索选完一味药后搜索框不清空；接着点字母会把面板收起来 | 选完清空搜索；点字母总是打开这个字母（不做「再点一次收起」） |
| 用「电话已存在 → 就用这个病人」选好病人后，再点「换一个」，回到的是填了一半的新建表单 | 选定病人时重置搜索和新建状态 |
| 新建病人后整页刷新，偶尔打断正在填的开方表单（按钮一直转） | 新建病人不再触发整页刷新 |
| 导航流式渲染时，占位导航和真实导航短暂同时存在 | 导航直接渲染 |
