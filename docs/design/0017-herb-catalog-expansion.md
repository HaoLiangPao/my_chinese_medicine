## 3. 名单的来源和取舍规则

1. **药名**以《中国药典》2020 年版一部的药材和饮片名为准（正名）。药名本身是事实；没有照抄教材或药典的文字。
2. **挑哪些**：《中药学》教材各章的正药和常用附药，加上临床处方里常见、药典单列的。药典没有单列、但教材收而且处方常写的，也收（竹叶、败酱草、白花蛇舌草、五灵脂、龙齿、琥珀，核对页上标「教」）。
3. **分类**：按教材的功效分类；附药跟主药放在同一类（莲子心、荷叶在收涩药）。补虚药照原来的目录分成补气、补血、补阴、补阳。炮制品的分类跟原药材。
4. **炮制品**：只收药典单列的饮片，或者处方里常见的写法（炙、炒、焦、制、煅、酒、醋、姜、盐、蜜、麸炒、炭），作为独立药材挂在原药材下面。
5. **别名**：俗写、简写、旧名、商品名（云苓、元胡、川军、龟板、夜交藤、白芥子……），以及炮制品的常见写法（炙麻黄 → 蜜麻黄、炒枳壳 → 麸炒枳壳）。**一个名字可能指两种药的，不设别名**（「萆薢」：粉萆薢还是绵萆薢）。别名不能和任何药名重名（`match_herb` 先按药名找）。
6. **拼音**：手写，多音字按药材的读法（苦参 ku shen、重楼 chong lou、莪术 e zhu、蛤壳 ge qiao、螵蛸 piao xiao、槟榔 bing lang），不用 pinyin-pro 现算（它会读错）。
7. **不收**：

| 药 | 原因 |
|---|---|
| 穿山甲、紫河车 | 药典已不再收载 |
| 马兜铃、天仙藤、青木香、关木通、广防己 | 含马兜铃酸，已撤销或停用 |
| 罂粟壳 | 麻醉药品管制 |
| 斑蝥、红粉、轻粉、砒石、巴豆 | 大毒，基本只外用或极少用，药柜一般不备 |
| 蟾酥、雄黄、硫黄、土荆皮、木鳖子 | 有毒，以外用或入中成药为主 |
| 茯神 | 药典没有单列（附在茯苓下）；E2E 场景用它测「目录里没有的药录入时自动新建」。用户需要时直接新增 |

### 拿不准、要李医生看的

- **同名异物 / 药典分列**：竹叶和淡竹叶（不同植物，都收）；葛根和粉葛；木通和川木通；五味子和南五味子；金钱草和广金钱草；金银花和山银花；橘红和化橘红；豆蔻、草豆蔻、肉豆蔻。
- **一药多名，取了药典正名**：龙胆（龙胆草）、赭石（代赭石）、益智（益智仁）、芥子（白芥子）、龟甲（龟板）、豆蔻（白豆蔻）、延胡索（元胡）、首乌藤（夜交藤）、蒺藜（刺蒺藜、白蒺藜）。括号里的是别名。
- **别名指向要确认**：「贯众」→ 绵马贯众（药典另有紫萁贯众）；「防己」就是粉防己（汉防己）。
- **规格合并**：附子的饮片药典分黑顺片、白附片、淡附片、炮附片，这一版合成「制附子」一味（别名熟附子、制附片）；冰片（合成龙脑）、天然冰片、艾片只收「冰片」。
- **保护动物来源**：麝香、牛黄、羚羊角按药材名收，实际多用人工麝香、人工牛黄 / 体外培育牛黄。
- **熟地黄**：药典里是地黄的炮制品，目录里原来就是单独一味（补血药），这次不改。
- **毒性**：核对页上的「小毒 / 有毒 / 大毒」按药典标注整理，没有逐条对照原文（山慈菇、蜂房、雷丸各版本说法不一）。毒性正式记在资料里（`herb_monographs.toxicity`），新药的资料还没写（§5）。

名单核对页（按分类分组、标出新增 / 已有、炮制品、别名、有毒的药）2026-11-13 发给 Hao 过目。

## 4. 怎么上线（和 0010 §3.4 一样的做法）

线上部署只执行 migration、不跑 `seed.sql`，所以：

1. `supabase/seed.sql` 是目录的正式来源（本地 / E2E 用），按分类排。
2. `scripts/gen-herb-monographs.mjs` 读 seed.sql 和资料 JSON，生成 migration：改名（沙参，已经做过，再跑不变）→ 全部药材、炮制品、别名（已有的不动）→ 资料（已有的不覆盖）。
3. 这次给生成脚本加了一条：**名字已经被别名占用的药不建**（比如管理员手工把「龙齿」设成过别名）——否则 `match_herb` 会从指向原来那味药变成指向新药，已经在用的写法结果变了。

已有数据怎么处理（升级测试 `supabase/tests/upgrade/20261113000025_herb_catalog_expand.sql` 覆盖）：

| 情况 | 做法 |
|---|---|
| 用户自己加过同名药（如「延胡索」，没有拼音和分类） | 不重复建、不改它（拼音、分类还是空的，页面上用 pinyin-pro 现算）；新的炮制品（醋延胡索）、别名（元胡）挂在它上面；已有处方不变 |
| 用户加过的药名正好是新别名（如把「云苓」建成了一味药） | 别名不建；输入「云苓」还是找到用户那味 |
| 用户加过的药名正好是新炮制品（如「红参」） | 不动，不挂到人参下 |
| 已有别名和新药同名（管理员加过「龙齿」→ 某味药） | 新药不建，别名不变 |
| 已有别名和新别名同名但指向不同 | 已有的不改 |

可以重复执行（升级测试里再跑一遍，药材、别名、资料的数量和 id 都不变）。只新增行，不改表结构，正在线上跑的旧代码不受影响。

## 5. 药材资料：这一版只加目录

325 味新药、63 个新炮制品**这一版没有资料草稿**。一次写 388 份性味、归经、功效、使用注意，质量没法保证，李医生也审不过来。做法：

- 详情页对没有资料的药正常显示（拼音、分类、别名、库存、方子），资料的位置写「资料还在整理中」。用户自己加的药（没有分类）不显示这句。
- 资料草稿按分类分批补（每批几十味，先补临床最常用的），每批照 0010 的格式写进 `herb-monographs.json`，用生成脚本出一个新的 migration（已有的不覆盖），还是 draft，等李医生审核。
- 核对页 `/review/herbs` 只列有资料的药，所以新药不会出现在待审核里，直到它的草稿导进来。

## 6. 选药界面

- 家庭录方 A–Z（RX-5）：507 条，C 组最长 53 味；字母条多了 A。建索引 + 搜一次在 50 ms 以内（单元测试量的）。
- 诊所开方（CLN-3）：430 条，S 组最长 44 味，手机上一屏多一点，可以接受；按首字母找不到时用搜索。
- **诊所开方加了别名搜索**：以前只搜汉字和拼音，搜「元胡」会提示「＋ 新增『元胡』」（点了其实选的是延胡索，但看起来像要新建一味药）。现在显示「元胡 → 延胡索」，不提示新增；别名指的是炮制品时（「炙麻黄」）直接选那个炮制品。
- **药材页的目录**按功效分类分组，默认收起（以前 500 多个标签平铺，手机上要滑很久）。
- 以后目录超过 1000 味时要注意：Supabase 的 API 默认一次最多返回 1000 行，`listHerbs` / `listHerbAliases` 要分页。
