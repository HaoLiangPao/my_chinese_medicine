## 2. 学习路径（草案，书目和顺序待李医生确认）

1. **入门：中医怎么看身体**：整体观、辨证论治；「为什么同一个病，不同的人吃不同的药」
2. **基础理论**：阴阳 → 五行与五脏 → 脏腑 → 气血津液 → 经络与穴位（每一课配一个交互图）
3. **中药入门**：四气五味、归经；常用药材图鉴；读懂一张药方（君臣佐使）。和家里的药柜连起来：从自己吃过的药开始认识
4. **经典**：《黄帝内经》（素问 · 灵枢）选读 → 《伤寒论》选读。形式是原文 + 白话 + 讲解

需要和李医生确认的：

- 每个阶段选哪几篇，按什么顺序
- 经典用哪个版本作底本
- 讲解由谁写、审，署谁的名字
- 哪些说法她不同意、要改

## 3. 内容来源与版权

| 内容 | 能不能直接用 | 做法 |
|---|---|---|
| 《黄帝内经》《伤寒论》**原文** | 古籍原文本身早已不受版权保护 | 可以用。但要选一个公开、标明可以引用的底本。[中国哲学书电子化计划（ctext）](https://ctext.org/tools/zhs?en=off) 有 API，但页面上没写古籍文本的授权条款，要先确认或联系主编 |
| 现代整理本的**标点、校勘、白话译文、注释** | 有版权 | 不复制。白话和讲解我们自己写，或者由李医生授权 |
| 李医生的讲解 | 她的作品 | 书面同意，署名 |
| 现代中医书籍（上传给 AI 做检索） | 自己学习可以 | 公开展示原文需要授权；公开页面只放我们自己写的内容 |
| 世卫组织《WHO 标准针灸经穴定位（西太平洋地区）》 | 书本身（文字、插图）有版权 | 穴位名称、国际代码（如 LI4 合谷）、定位规则这些事实可以引用；插图不能拿来用 |

## 4. 动态图怎么做最直观

### 结论

**需要准确的部分（位置、关系、文字）用代码画；AI 生成的图片和视频只用来做插画和情境短片。**

原因：

- AI 生图会编造解剖细节，而穴位位置差一点就是错的。做科学插图的建议流程是：AI 出底图，文字和标注用矢量图层叠加，解剖准确性必须另外人工核对（[来源](https://scholarviz.com/blog/2026-image-generation-model-landscape-for-scientific-figures)）。
- 代码画的图（SVG、Canvas、3D）一处修改，所有地方同步。它可以交互：点一下、拖一下，比看视频更容易懂。
- 代码画的图能被测试：比如「木生火」的箭头必须存在。原型已经这样做了。

### 每种图的方案

| 图 | 方案 | 难度 | 状态 |
|---|---|---|---|
| **阴阳太极** | SVG + CSS 动画：太极缓慢旋转；外圈十二时辰；拖动时间看一天中阴阳消长，也可以自动播放 | 低 | ✅ 原型 `/learn/yinyang` |
| **五行生克** | SVG 交互：相生是外圈弧线，相克是五角星连线，箭头流动。点一行，显示它和其他四行的关系（我生 / 生我 / 我克 / 克我），以及对应的脏腑、季节、颜色、五味、五志、开窍 | 低 | ✅ 原型 `/learn/wuxing` |
| **五脏六腑** | 第一步：2D 人体剪影（SVG），脏腑是可以点的区域，和五行图联动（点「肝」同时高亮「木」）。第二步：3D（见下） | 中 | 规划 |
| **经络与穴位** | 第一步：2D 正面 / 背面 / 侧面图，先做约 20 个常用穴（合谷、足三里、内关、百会、三阴交、太冲……），每个穴位的位置由李医生核对。第二步：3D 人体 + 自己标注的穴位坐标 | 高 | 规划 |
| **中药图鉴** | **真实照片**（自己拍家里罐子里的药材，版权最清楚），不用 AI 图 | 低 | 规划 |
| **情境短片**（季节与五行、煎药过程） | AI 视频生成 10 秒左右的短片，或者用代码动画导出成视频 | 中 | 可选 |

### 3D 人体从哪里来

- **[Z-Anatomy](https://github.com/Z-Anatomy/Models-of-human-anatomy)**：开源的人体解剖 3D 模型（Blender 格式），基于日本的 BodyParts3D。
  - 授权是 **CC BY-SA 4.0**：要署名，修改后的模型也要用同样的授权公开。
  - 其中少数模型（肾脏、内耳）是「非商业」授权，要避开。
  - 做法：在 Blender 里导出需要的部分（皮肤、主要脏器）为 glTF，网页用 three.js / react-three-fiber 显示。
- **现成的穴位数据集基本不能直接用**：
  - 学术数据集 [acusim](https://datadryad.org/dataset/doi:10.5061/dryad.zs7h44jkz) 只覆盖头颈部 174 个穴位，13 GB 合成图像，授权没写清楚。
  - 应用商店里的 3D 穴位 App 都是闭源的。
  - 所以穴位坐标要自己在模型上标，按国际标准的定位规则，再由李医生核对。这是整个学堂最费工的一块，建议放在最后。

### AI 图片 / 视频模型能做什么

- **图片**：适合封面插画和情境插画（比如「春天、东方、青色」这样的意境图）。
  - 文字渲染强的：Gemini 3 Pro Image（多语言文字较好）、GPT Image 1.5。
  - Recraft V3 能直接输出 SVG（同上[来源](https://scholarviz.com/blog/2026-image-generation-model-landscape-for-scientific-figures)，2026 年 2 月）。
  - 即使这样，图里的文字也建议后期用矢量覆盖，不要相信模型拼的字。
- **视频**：目前主流的是 Veo 3.1、Kling 3.0、Sora 2、Seedance 2.0、Runway Gen-4.5，开源有 Wan 2.6。
  - 适合几秒到十几秒的情境短片。
  - Seedance API 约 $0.14/秒，Kling 约 $0.5/条（[来源](https://lushbinary.com/blog/ai-video-generation-sora-veo-kling-seedance-comparison/)，2026 年 4 月，厂商文章，价格以官网为准）。
  - 物理和细节仍然不稳定，**不适合讲解型的精确图**。
- **代码动画导出视频**：如果以后要发小红书、视频号，可以用同一套 SVG 组件生成讲解视频，保证视频和网页内容一致。
  - [GSAP](https://webflow.com/blog/gsap-becomes-free) 2025 年起全部插件免费、可商用。
  - Remotion 可以用 React 写视频（对个人和小团队免费，用前确认授权）。

## 5. 实施顺序

| 阶段 | 内容 |
|---|---|
| 3.0 ✅ | 学堂框架（公开路径、学习路径页）+ 阴阳、五行交互图，带单元测试和 E2E |
| 3.1 | 文字课程：内容先用 Markdown/MDX 放在仓库里，李医生审核后上线；脏腑 2D 图，和五行联动 |
| 3.2 | 中药图鉴：药材表加性味、归经、功效字段；配真实照片；从「我家吃过的药」进入 |
| 3.3 | 经典选读：原文 + 白话 + 讲解；「问书」检索问答（只解释书里的内容，附出处，不给用药建议） |
| 3.4 | 穴位：先 2D 20 个常用穴，李医生核对后再做 3D |
| 以后 | 给李医生一个在线编辑和审核内容的界面（和 MVP4 医生角色一起做） |
