## 1. 为什么

2026-11-14 Hao：做一个中医类的素材库；药材很多，点开看的时候想要「随机打开 page 的感觉」，由一个住在 App 里的「中医小学徒」来做——小学徒在药柜前读书、学习，用户点开药材页时随机做一个动作（先五个，以后再加，比如捣药、读书、针灸），旁边一个说话框讲一句药材知识。

## 2. 素材库

位置：`web/src/components/art/`。全部是我们自己画的 SVG React 组件，原创形象，不模仿任何现有的卡通角色、品牌或游戏。

| 文件 | 素材 | 说明 |

画法的约定（以后加素材照这个来）：

1. **颜色**：全部用 `palette.ts` 的固定颜色，不用主题变量（2026-11-17 起，§9.2）。所有图都画在宣纸色的画片上（`Picture`），浅色、深色模式下画片里是同一套颜色。
2. **坐标**：道具都接收 `x`、`y`，直接画在场景的坐标里，不用 `transform`。原因：秤杆晃这类动画的转动中心写成 `transform-origin: <x>px <y>px` + `transform-box: view-box`，带动画的 `<g>` 外面不能再有 `transform`，否则中心会偏。小学徒的身体和头内部用 `translate` 画（以脚底 / 头的中心为原点），所以头的动画（点头、转头）改用 `transform-box: fill-box`，转动中心是头的外框下沿（脖子），外面有 `transform` 也不偏。
3. **场景**：viewBox 统一 `0 0 160 120`，小学徒的脚在 y ≈ 105。
4. **动画**：轻、慢、循环 1.6–4.5 秒；`prefers-reduced-motion: reduce` 时全部停下，停在静态姿势（`motion.css`（类名常量在 `motion.ts`） 最后一段）。

素材都摆在 `/herbs/apprentice`（「认识小学徒」，从药材目录页的小学徒下面进），加素材时在这一页对照效果。

## 4. 说话框台词

硬规则（CLAUDE.md）：**AI 只做转录和科普，不生成面向患者的用药 / 剂量建议。** 所以台词只讲知识和学习感受：不说「这个患者可能需要……」，不说用量。

**来源只用确定的数据**（`herbLines()`，`web/src/lib/apprentice.ts`）：

| 数据 | 台词（例） |
|---|---|
| 拼音 | 茯苓，拼音 fu ling。先把字认准，抓药才不会抓错。 |
| 功效分类 | 茯苓归在利水渗湿药里，我在一类一类地背。 |
| 同一类的其他原药材（随机三味） | 我在背利水渗湿药：茯苓、猪苓、泽泻、薏苡仁…… |
| 别名 | 茯苓也写作云苓、白茯苓。方子上看到别的写法，也要认得是它。 |
| 炮制品 → 原药材 | 蜜麻黄是麻黄的炮制品。师父说炮制不同，用法也不同，抓药时要看清。 |
| 原药材 → 炮制品 | 大黄还有酒大黄、熟大黄、大黄炭这些炮制品。师父说炮制不同，用法也不同，抓药时要看清。 |
| **已审核**的药材资料 | 性味归经、传统用途（注明「中医传统用法」）、来源、道地产区、选品、炮制、保存、毒性（有毒的说「要格外仔细核对」） |

- **草稿资料一句都不用**（还没经医生审核）；审核人标了「有问题」（`flag_note`）的也不用。炮制品用原药材的资料、而原药材是草稿时，`resolveMonograph` 已经把整份标成草稿，也不用。
- **不用「使用注意」**：讲的是谁不能用、怎么用，最接近用药建议，留在资料区按原文显示。
- 手写的通用台词在 `web/src/lib/apprentice-lines.ts`（「抓药前先核对方子」「十八反、十九畏，我天天念」……），直接往里加。
- **禁用字眼**（`FORBIDDEN`）：用量（克、g、钱、两、斤、毫升、ml）、服法（服用、内服、煎服、每日、每天、一次）、针对病人（患者、病人、需要、建议、应该吃……）。
  - 手写台词整句检查（单元测试）。
  - 从数据拼的台词先去掉药名、拼音、别名再检查（金钱草、两面针、拼音里的 g 不算），**有禁用字眼的那一句就不说**（运行时也过滤）。现在的资料草稿里只有半夏的炮制写了「内服」，那一句不会说。
  - 单元测试把整个目录（507 味）+ 资料草稿（当作已审核）跑一遍：检查**过滤以前**拼出来的台词（`composeHerbLines`），只有半夏的炮制那一句有禁用字眼（模板本身写错的话每味药都会出现）；过滤后每味至少 3 句。
- 拼不到 3 句的（比如涌吐药只有常山一味）用通用台词补到 3 句；用户自己加的药（什么数据都没有）说「目录里还没有它的资料，我得去问问师父」+ 通用台词。
- 目录页的台词：「目录里有 507 味药，我一天认几味，慢慢来。」+ 通用台词。不说「药柜」：家庭账号的「药柜」是自己的库存（`terms.ts`），会以为自己有这么多味。
- 说话框底部一行小字：「小学徒在学习，仅为中药知识，不作用药建议」。
- 点一下说话框换一句（按洗好的顺序循环，不会连着两次一样）。

**随便翻一味**（`components/apprentice/actions.ts`，server action，只读）：

- 默认范围：全站目录（有功效分类的药，507 味），**不含用户自己加的药**（`herbs` 是全站共用的表，别人加的药名不该被翻出来，也没有资料）。

- 打开的地址带 `?flip=mine|all`（实际用到的范围），详情页的「再翻一味」沿用这个范围，并且不翻到正在看的这味；药柜里除了这味没有别的了，就翻全站目录。
- 用 `<form action>` + `redirect()`：没加载完 JS 也能用（表单直接提交）。

## 6. 随机放在哪里

**服务端**：每次渲染生成一个种子（`newSeed()`），用它挑动作、洗台词顺序，结果作为 props 交给客户端组件；客户端只是按顺序往下念。服务端和浏览器渲染出来的一样，没有 hydration 不一致。

纯函数（`seededRandom` mulberry32、`pickIndex`、`pickAction`、`shuffle`、`herbLines`、`forbiddenWords`）都在 `web/src/lib/apprentice.ts`，单元测试：同一个种子结果一样、1000 个种子里五个动作都出现而且大致一样多。

Cache Components 是关闭的，药材页本来就是每次请求都渲染（要读登录状态），所以每次打开都是新的随机。

## 9. 小学徒的角色设定（2026-11-17）

2026-11-15 Hao：现在的小药童「稍微有点奇怪」，想要更细致的表达；动作类型保留，整体形象可以换。做了一张风格对比页（圆润卡通风、手绘温暖风、中国水墨风、简笔画风、剪纸风）给 Hao 选，他选了**手绘温暖风**，头和眼睛放大，深色模式垫宣纸色的底。

版权：对比页里的「圆润卡通风」「手绘温暖风」只借了大致的美术气质（Hao 原话说的是迪士尼、吉卜力风格），小学徒是我们自己设计的原创角色，不照着任何现有角色画，所有图都是手写的 SVG。

### 9.1 造型和比例

- **头**：头顶两个发髻（双丫髻），各系一根朱砂红的发带（取代原来的黑帽红结，红色这个记号保留）；有刘海、耳朵、两缕发丝。
- **衣服**：松绿交领长衫，左襟压右襟；米色内领；宽袖，袖口有米色镶边，袖子下沿因为重力多垂一点。
- **腰间**：琥珀色腰带，结垂在左边（看图的人的左边）；右边挂一个浅棕色的小药囊，系一个朱砂红的扣。
- **比例**（以脚底中点为原点，场景里脚底在 y = 105）：头的中心 y = −63、半径 17；肩 y = −48，腰 y = −30；肩宽的一半 11，下摆宽的一半 17。头身比约 1 : 2.4——比真的小孩头大、眼睛大，是为了在详情页的小图（107×80 像素）里也看得清表情。
- **手**：从袖口伸出来的小圆手（半径 3.1）；捧书、握杵、拱手时手画在东西前面。

### 9.2 配色和线条

| 用途 | 颜色 |
|---|---|
| 画片底 / 边 | `#f6f1e7`（宣纸色）/ `#e2d9c8` |
| 线条 | `#5b4535` 暖棕，粗 0.6–0.9（衣服 0.9，脸和手 0.8，头发 0.6） |
| 长衫 / 腰带 / 发带 | 松绿 `#3d6b58` / 琥珀 `#b7791f` / 朱砂 `#a8372a`（App 浅色主题的值） |
| 皮肤 / 头发 / 五官 | `#f1d1b0` / `#3a2c22` / `#3a2a20` |
| 镶边、内领 | `#efe3c8` |
| 木头、抽屉、石头 | `#b9894f`、`#d9b98a`、`#a0968a` |

- 全部是固定颜色，写在 `palette.ts`；画片在深色模式下也是宣纸色，所以不用主题变量。
- 每种东西都是「填色 + 暖棕描边」；明暗用半透明的黑（右半边 8–10%），褶子用 35% 的暖棕细线。
- 手绘感来自 `Picture` 的滤镜：低频的噪声让边缘轻轻地抖（`baseFrequency 0.07`、位移 1.6），不要调高频率，否则边缘会变成毛茸茸的。

### 9.3 表情集

`ApprenticeHead` 的 `face`：

| face | 名字 | 眼睛 | 眉毛 | 嘴 | 用在哪里 |
|---|---|---|---|---|---|
| `neutral` | 平常 | 睁眼，两个高光，会眨 | 平的弧 | 小的笑 | 称药、翻药斗、素材库的立绘 |
| `happy` | 开心 | 眯成弯弯的 | 往上挑 | 张开笑，露一点舌头 | 以后答对题、打招呼 |
| `focus` | 认真 | 眼睛往下看（小一点、低一点），会眨 | 平 | 小圆嘴 | 读书、捣药、练针灸 |
| `confused` | 困惑 | 一只大一只小 | 一边挑高、一边压低 | 波浪线 | 以后「目录里还没有它的资料」 |
| `sorry` | 抱歉 | 闭眼（往下弯） | 眉头往上 | 小小的撇嘴 | 鞠躬 |

`look`（−1 … 1）让眼珠往左右看：称药、翻药斗、练针灸时看着右边的东西。

### 9.4 线条和画法规则（以后加素材照这个来）

1. 画在 `Picture` 里（场景用 `ApprenticeScene` 已经包好了）；颜色只用 `palette.ts`，新颜色先加到那里。
2. 填色 + 暖棕描边，用 `paint.xxx` 展开；不要用纯黑描边，不要用主题变量。
3. 小学徒站着用 `StandingApprentice`，胳膊用 `Sleeve` 从 `shoulders(cx)` 伸出去；手要画在拿着的东西前面时，先 `hand={false}` 画袖子，再画东西，最后 `Hand`。
4. 道具用绝对坐标；带转动动画的道具用 `view-box` 的转动中心（§2 第 2 条）。
5. 尺寸：小学徒的脚在 y = 105，头顶（含发髻）在 y ≈ 21；场景里留出说话框那一侧的空间，道具放在右边。
6. 在 `/herbs/apprentice` 上对照效果，再在详情页的小尺寸（107×80）和手机上看一遍。

### 9.5 以后加动作的规范

- 一个动作 = 一个场景函数（`scenes.tsx`）+ `APPRENTICE_ACTIONS` 一行（§3）。
- 选一个表情（`face`），眼睛看着手里的东西（`look`）；只让**一个部分**动（头、手里的东西、或者道具），1.6–4.5 秒循环；`prefers-reduced-motion` 时停在静态姿势（`motion.css` 最后一段加上新的类名）。
- 道具先加到 `props.tsx`（素材库页也摆一份），再在场景里用。
