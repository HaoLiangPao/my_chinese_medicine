## 1. 为什么

2026-11-14 Hao：做一个中医类的素材库；药材很多，点开看的时候想要「随机打开 page 的感觉」，由一个住在 App 里的「中医小学徒」来做——小学徒在药柜前读书、学习，用户点开药材页时随机做一个动作（先五个，以后再加，比如捣药、读书、针灸），旁边一个说话框讲一句药材知识。

| 文件 | 素材 | 说明 |

| `motion.css`（类名常量在 `motion.ts`） | 动画 | `nod` 点头、`look` 转头、`pound` 捣、`puff` 药末、`tilt` 秤杆晃、`pull` 拉抽屉、`poke` 进针、`glow` 穴位闪、`blink` 眨眼 |

画法的约定（以后加素材照这个来）：

1. **颜色**：衣服、木头、线条用主题变量（`--jade` `--amber` `--cinnabar` `--ink` `--muted` `--line` `--card` `--paper`），浅色 / 深色模式自动换。脸（`SKIN`）、帽子和鞋（`DARK`）、铜人（`BRONZE`）、针（`STEEL`）、书卷的纸和字（`SCROLL_PAPER`、`SCROLL_TEXT`）用固定颜色——深色模式下 `--ink` 是浅色，画在脸上看不清；`--paper` 是深色，书卷会变成一块黑。
2. **绝对坐标**：素材都接收 `x`、`y`，直接画在场景的坐标里，不用 `transform`。原因：动画的转动中心写成 `transform-origin: <x>px <y>px` + `transform-box: view-box`，带动画的 `<g>` 外面不能再有 `transform`，否则中心会偏。
3. **场景**：viewBox 统一 `0 0 160 120`，小学徒的脚在 y ≈ 105。
4. **动画**：轻、慢、循环 1.6–4.5 秒；`prefers-reduced-motion: reduce` 时全部停下，停在静态姿势（`motion.css`（类名常量在 `motion.ts`） 最后一段）。

素材都摆在 `/herbs/apprentice`（「认识小学徒」，从药材目录页的小学徒下面进），加素材时在这一页对照效果。

## 3. 五个动作

`web/src/components/apprentice/scenes.tsx`：

| id | 名字 | 画面 | 动画 |
|---|---|---|---|
| `read` | 读书 | 站在药柜前，双手捧着打开的书卷 | 点头 |
| `pound` | 捣药 | 双手握杵，药臼在身边 | 杵一下一下地捣，药末飞起来 |
| `weigh` | 称药 | 右手提着戥子 | 秤杆轻轻晃 |
| `drawer` | 翻药柜 | 伸手拉药柜的抽屉 | 抽屉拉出来再推回去，头转过去看 |
| `needle` | 练针灸 | 对着铜人，手里拿着针 | 针一进一退，穴位一闪一闪 |

睁眼的动作都会眨眼。

**加一个动作**：`web/src/lib/apprentice.ts` 的 `APPRENTICE_ACTIONS` 加一行（id + 中文名），`scenes.tsx` 写一个场景组件、在 `SCENES` 里加一行（`Record<ApprenticeAction, …>`，漏了 TypeScript 会报错）。单元测试「五个动作都可能出现」要跟着改成六个。

## 4. 说话框台词

硬规则（CLAUDE.md）：**AI 只做转录和科普，不生成面向患者的用药 / 剂量建议。** 所以台词只讲知识和学习感受：不说「这个患者可能需要……」，不说用量。

**来源只用确定的数据**（`herbLines()`，`web/src/lib/apprentice.ts`）：

| 数据 | 台词（例） |
|---|---|
| 拼音 | 茯苓，拼音 fu ling。先把字认准，抓药才不会抓错。 |
| 功效分类 | 茯苓归在利水渗湿药里，我在一类一类地背。 |
| 同一类的其他原药材（随机三味） | 我在背利水渗湿药：茯苓、猪苓、泽泻、薏苡仁…… |
| 别名 | 茯苓也写作云苓、白茯苓。方子上看到别的写法，也要认得是它。 |
| 炮制品 → 原药材 | 蜜麻黄是麻黄的炮制品。师父说炮制不同，用法也不同，抓药时要看清。 |
| 原药材 → 炮制品 | 大黄还有酒大黄、熟大黄、大黄炭这些炮制品。师父说炮制不同，用法也不同，抓药时要看清。 |
| **已审核**的药材资料 | 性味归经、传统用途（注明「中医传统用法」）、来源、道地产区、选品、炮制、保存、毒性（有毒的说「要格外仔细核对」） |

- **草稿资料一句都不用**（还没经医生审核）。炮制品用原药材的资料、而原药材是草稿时，`resolveMonograph` 已经把整份标成草稿，也不用。
- **不用「使用注意」**：讲的是谁不能用、怎么用，最接近用药建议，留在资料区按原文显示。
- 手写的通用台词在 `web/src/lib/apprentice-lines.ts`（「抓药前先核对方子」「十八反、十九畏，我天天念」……），直接往里加。
- **禁用字眼**（`FORBIDDEN`）：用量（克、g、钱、两、斤、毫升、ml）、服法（服用、内服、煎服、每日、每天、一次）、针对病人（患者、病人、需要、建议、应该吃……）。
  - 手写台词整句检查（单元测试）。
  - 从数据拼的台词先去掉药名、拼音、别名再检查（金钱草、两面针、拼音里的 g 不算），**有禁用字眼的那一句就不说**（运行时也过滤）。现在的资料草稿里只有半夏的炮制写了「内服」，那一句不会说。
  - 单元测试把整个目录（507 味）+ 资料草稿（当作已审核）跑一遍：每句都没有禁用字眼，每味至少 3 句。
- 拼不到 3 句的（比如涌吐药只有常山一味）用通用台词补到 3 句；用户自己加的药（什么数据都没有）说「目录里还没有它的资料，我得去问问师父」+ 通用台词。
- 目录页的台词：「药柜里有 507 味药，我一天认几味，慢慢来。」+ 通用台词。
- 说话框底部一行小字：「小学徒在学习，仅为中药知识，不作用药建议」。
- 点一下说话框换一句（按洗好的顺序循环，不会连着两次一样）。

## 5. 出现在哪里

| 页面 | 内容 |
|---|---|
| 药材目录 `/herbs` | 最上面一张卡片：小学徒（随机动作）+ 说话框 +「🎲 随便翻一味」+「只翻药柜（诊所：库存）里有的」+「认识小学徒 →」 |
| 药材详情 `/herbs/[id]` | 药名、资料标签下面、三个数字上面：小号的小学徒 + 说话框（这味药的知识）+「🎲 再翻一味」 |
| 认识小学徒 `/herbs/apprentice` | 五个动作、鞠躬、全部道具（素材库的展示页） |
| 开方、处方、录方、库存、总览 | **不放**，免得打扰干活 |

页面里只加一行组件（`<ApprenticeCorner />`、`<HerbApprentice … />`），代码都在 `web/src/components/apprentice/`。

**随便翻一味**（`components/apprentice/actions.ts`，server action，只读）：

- 默认范围：全站目录（有功效分类的药，507 味），**不含用户自己加的药**（`herbs` 是全站共用的表，别人加的药名不该被翻出来，也没有资料）。
- 勾「只翻药柜里有的」：现在库存 > 0 的药（自己加的也算，因为是自己的）。药柜是空的时勾不了；万一是空的，退回全站目录。
- 打开的地址带 `?flip=mine|all`，详情页的「再翻一味」沿用这个范围，并且不翻到正在看的这味。
- 用 `<form action>` + `redirect()`：没加载完 JS 也能用（表单直接提交）。

## 6. 随机放在哪里

**服务端**：每次渲染生成一个种子（`newSeed()`），用它挑动作、洗台词顺序，结果作为 props 交给客户端组件；客户端只是按顺序往下念。服务端和浏览器渲染出来的一样，没有 hydration 不一致。

纯函数（`seededRandom` mulberry32、`pickIndex`、`pickAction`、`shuffle`、`herbLines`、`forbiddenWords`）都在 `web/src/lib/apprentice.ts`，单元测试：同一个种子结果一样、1000 个种子里五个动作都出现而且大致一样多。

Cache Components 是关闭的，药材页本来就是每次请求都渲染（要读登录状态），所以每次打开都是新的随机。

| # | 决定 | 理由 | 备选 |
|---|---|---|---|
| 1 | **「这个患者可能需要茯苓」改成学习口吻**：「我在背利水渗湿药：茯苓、猪苓、泽泻……」「大黄还有酒大黄、熟大黄、大黄炭这些炮制品，师父说炮制不同，用法也不同」 | 项目硬规则：AI 只做转录和科普，不生成面向患者的用药建议。针对病人说「可能需要某药」就是用药建议，哪怕是卡通人物说的；李医生的病人也可能看到屏幕 | 以后如果要「病例练习」类的内容，只能用李医生自己写、审核过的教学病例，并且明确标「教学案例」，不针对当前的病人 |
