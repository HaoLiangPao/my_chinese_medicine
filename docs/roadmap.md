## 协作上踩过的坑

- 本地 E2E 环境用固定端口，`scripts/local-stack.sh up` 会先 `down`：两个 session 不能同时跑 E2E。
- `backups/` 里是真实数据：只看文件名，不打开、不上传、不提交。
- 恢复备份到普通 Postgres 要先跑 `scripts/backup-restore-prep.sql`（PR #24）。
- 临时 Postgres 放在很深的目录下时 Unix socket 路径会超长，用 `-c unix_socket_directories=''` 只走 TCP。
- session 报告「做完了」之后要自己看 diff 和 CI，再告诉 Hao。
